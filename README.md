# Pit Wall Manager

Jogo de gestão de equipe de Fórmula 1 para navegador, em HTML, CSS e JavaScript puro (um único arquivo).

## Como jogar

Abra o link do GitHub Pages deste repositório no navegador. Não precisa instalar nada.

O progresso é salvo no navegador de cada pessoa (localStorage). Limpar os dados do site apaga o save.

## Como testar e dar feedback

1. Clique em **Novo jogo**, escolha a temporada e a equipe e digite o nome do chefe de equipe.
2. Jogue algumas corridas e passe pela virada de temporada.
3. Se encontrar um erro, abra uma **Issue** com: o que você fez, o que esperava e o que aconteceu (de preferência com print).

Este jogo é um projeto de fãs, sem vínculo com a Fórmula 1. Os nomes de patrocinadores são fictícios.
